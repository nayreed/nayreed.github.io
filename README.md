# Nayreed's Resume 🌐

Welcome to my personal portfolio website! This site showcases my **skills, projects, and experiences** in a sleek and interactive manner.

## 🚀 Features
- **React + Vite** for a fast and optimized development experience.
- **Responsive Design** for a seamless user experience across devices.
- **Dark Mode UI** with a modern and professional aesthetic.
- **Skills & Languages Toggle** to switch between different skill categories.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, JavaScript, HTML5, CSS
- **UI Libraries:** Tailwind CSS, ShadCN, Lucide Icons
- **Version Control & Hosting:** Git, GitHub Pages
